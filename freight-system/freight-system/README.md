# 運費系統（和陞／和聖 運費／帳務管理系統）

多人共用的雲端運費與帳務管理系統，使用 Next.js + PostgreSQL 打造，可部署到雲端讓多台電腦同時登入使用。

## 目前已完成功能

1. **帳號登入與角色權限**：Email + 密碼登入，資料存放於雲端資料庫，多人可同時使用。分為「管理者／會計（完整權限）」與「司機（僅能看自己的薪資、改密碼）」兩種角色。
2. **司機管理**：姓名、電話、底薪、抽成比例、支出費用預設由誰負擔；可設定每月固定扣款（例如勞健保）。
3. **運費單**：記錄每筆運費，並可個別輸入「扣發票稅」「扣利息」「車主支出費用」，且可選擇該筆支出是算在「司機身上」還是「公司成本」。支援特殊鐵板計價（見下）。
4. **鐵板計價**：於運費單明細輸入長、寬、厚、重量，系統依「長寬取最大值」自動查價格區間表，換算單價並乘以重量算出金額，多筆明細加總後自動寫回運費單總額。價格區間表可自行新增／刪除。
5. **薪資結算**：依月份自動計算每位司機的應發薪資——若有底薪，會自動比較「抽成金額」與「底薪」取較高者，再扣除發票稅、利息、司機負擔的支出費用及固定扣款，算出實發金額（邏輯與 Excel 手算方式相同）。司機登入後可在「我的薪資」查看自己的結算明細。
6. **費用管理**：可自訂費用分類（成本 / 費用），並可將某筆費用設為「每月固定費用」，系統會自動套用到之後每個月，不需要每月手動輸入。
7. **損益表**：依月份自動彙總運費收入、其他收入、司機薪資成本、公司負擔的車主支出、其他成本與費用，算出本期損益。
8. **應收帳款**：可關聯到某張運費單，記錄付款方式（匯款／支票／現金／其他）與是否已付款，並有未收款總額提醒。
9. **支票登記簿**：登記收到／開出的支票，追蹤兌現狀態與到期日，儀表板會提醒 30 天內到期的支票。
10. **員工管理**：個人資料、勞健保資訊、薪資設定，可獨立匯出 Excel。
11. **車輛管理**：車牌、車型、所屬車行、保險公司、保險與驗車到期日，儀表板會提醒 30 天內到期的車輛。
12. **發票登記（和陞／和聖）**：可分別登記「和陞」與「和聖」兩個開票名稱的銷項／進項發票，並可依公司別分別匯出 Excel。
13. **單價表**：可依客戶設定常態運費單價，並匯出 Excel。
14. **客戶管理**、**帳號管理**（可新增其他登入帳號，含司機角色帳號）、**變更密碼**。

所有清單資料（員工、發票、單價表）皆可一鍵匯出 Excel（.xlsx）檔案。

## 本機開發

需求：Node.js 18+、PostgreSQL 資料庫（本機或雲端皆可）。

```bash
npm install
cp .env.example .env   # 編輯 .env，填入 DATABASE_URL 與 JWT_SECRET
npm run db:push         # 建立資料表
npm run db:seed         # 建立第一個管理者帳號（admin@example.com / admin1234）
npm run dev              # 開發模式，瀏覽 http://localhost:3000
```

正式環境請改用：

```bash
npm run build
npm run start
```

## 部署到雲端（多人可連線使用）
